# Фикстура: лонгтап на тайле открывает контекст-меню

**devices:** pc-fixture
**preconditions:** ничего ставить не надо. Поднять статику фикстуры и оставить её работать:

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory test/fixture
```

`devices.example.json` уже содержит устройство `pc-fixture` с `url: "http://127.0.0.1:8080"` и профилем `apps/fixture.json`. Это единственный кейс в репозитории, исполнимый сразу после клона — без ТВ, без продуктового dev-сервера. Он же служит образцом формата: то же самое пишется для реального приложения, меняются только селекторы из его app-профиля.

## Шаги

Весь кейс — одним `tv_sequence`: между шагами ничего не вклинивается, а в отчёте видно время и вердикт каждого:

```json
{
  "device": "pc-fixture",
  "steps": [
    {"launch": {"relaunch": true}},
    {"wait": {"selector": ".demo-tile"}, "timeoutMs": 20000},
    {"goto": {"direction": "RIGHT", "selector": ".demo-tile", "maxSteps": 4}},
    {"longpress": "ENTER", "durationMs": 1200},
    {"expect": {"selector": ".demo-popup"}, "timeoutMs": 5000},
    {"press": "BACK"},
    {"expect": {"selectorGone": ".demo-popup"}, "timeoutMs": 5000}
  ]
}
```

**expect:** `ok: true` и семь зелёных шагов. Лонгтап (1200 мс > порога 800 мс в фикстуре) открывает `.demo-popup`; короткое нажатие его не открывает — это и есть проверяемый контракт.
**verify:** auto.

## Меню

Отдельным вызовом, без сценария:

```json
{"device": "pc-fixture", "select": false}
```

`tv_menu` без имени раздела возвращает список: `Main`, `Library`, `Following`, `Settings`. С именем — заходит в раздел: `{"device": "pc-fixture", "item": "Settings"}`.

## Что этот кейс подтверждает

- браузерный адаптер поднимает свой Chrome, грузит `url` и цепляется по CDP;
- `tv_goto` двигает фокус по семантике (`селектор`), а не по счётчику нажатий;
- лонгтап действительно удерживает клавишу: keydown → hold → keyup, и приложение различает клик и удержание;
- `expect` валит шаг, если попап не появился или не закрылся, — вердикт не зависит от глаз человека.

Тот же путь автоматизирован в `npm run check:browser` (`test/phase2-check.mjs`), где фикстура поднимается на свободном порту сама.
